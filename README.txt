# New Heroes: The First Steps — Site

Site mobile-first criado para o servidor de RP.

## Estrutura
- `index.html` — estrutura do site.
- `styles.css` — visual, responsividade e animações.
- `script.js` — textos, personagens, notícias e painel de edição.
- `assets/` — artes e logo fornecidas.

## Como abrir
Abra `index.html` no navegador. Não é necessário instalar nada.

## Como atualizar
Há duas formas:
1. Pelo próprio site, em `☰ > Personalizar / Atualizar`. As alterações de texto ficam salvas no navegador usado.
2. Para uma atualização pública para todos os jogadores, edite os dados no `script.js` e substitua os arquivos publicados na hospedagem.

## Importante sobre o painel
A versão entregue é estática e não possui banco de dados/login de administrador. Portanto, as alterações feitas pelo painel local não são enviadas para outros celulares. Para isso, o próximo passo seria conectar o site a um banco de dados e um login de administrador.
